# ARREST GAME - Test Guide

## 1. Startup

* [ ] Paper起動
* [ ] Skript読み込み成功
* [ ] Skriptエラーがない
* [ ] ARREST GAMEがOFFで開始しても問題ない

---

# 2. ON / OFF

## ON

```text
/arrest on
```

* [ ] ARREST GAMEがONになる
* [ ] 対象ワールドが設定される
* [ ] 犯罪チェックが開始される

## OFF

```text
/arrest off
```

* [ ] ARREST GAMEがOFFになる
* [ ] 犯罪チェックが停止する
* [ ] OFF中は犯罪を起こしても逮捕されない

## Status

```text
/arrest status
```

* [ ] ON / OFF状態を確認できる
* [ ] 対象ワールドを確認できる

---

すべての犯罪で共通する条件。

* [ ] 犯罪が検知される
* [ ] 逮捕される

* [ ] 犯罪が検知されない
* [ ] 逮捕されない

#### Adventure

* [ ] Adventureで犯罪を起こす
* [ ] 犯罪が検知されない
* [ ] 逮捕されない

#### Spectator

* [ ] Spectatorで犯罪を起こす
* [ ] 犯罪が検知されない
* [ ] 逮捕されない

---

# 4. World Check

## 対象ワールド

* [ ] 対象ワールドで犯罪を起こす
* [ ] 犯罪チェックが動作する
* [ ] 逮捕される

## 対象ワールド以外

* [ ] 別ワールドへ移動
* [ ] 同じ犯罪を起こす
* [ ] 犯罪チェックが動作しない
* [ ] 逮捕されない

## ON/OFF + World

* [ ] `/arrest off`
* [ ] 対象ワールドで犯罪を起こす
* [ ] 逮捕されない
* [ ] `/arrest on`
* [ ] 再び犯罪チェックが動作する

---

# 5. Individual Crime Check

個別犯罪では、**犯罪条件そのものの検知だけを確認する。**

逮捕処理・牢屋・BossBar等は共通処理として別項目で確認する。

## Grass - 環境破壊罪

* [ ] Survival

* [ ] 対象ワールド

* [ ] 短い草を破壊

* [ ] 犯罪が検知される

* [ ] 背の高い草を破壊

* [ ] 犯罪が検知される

## Flower - 花踏み

* [ ] Survival

* [ ] 対象ワールド

* [ ] 花の上に乗る

* [ ] 犯罪が検知される

* [ ] 複数種類の花で検知される

## Idle - サボり罪

* [ ] Survival

* [ ] 対象ワールド

* [ ] 30秒間移動しない

* [ ] 犯罪が検知される

* [ ] 移動するとタイマーがリセットされる

* [ ] 30秒未満では犯罪にならない

## Drop - 不法投棄罪

* [ ] Survival
* [ ] 対象ワールド
* [ ] アイテムを捨てる
* [ ] 犯罪が検知される

---

# 6. Arrest Common Processing

犯罪が検知された後の共通処理。

* [ ] プレイヤーが逮捕される
* [ ] 罪状が表示される
* [ ] Titleが表示される
* [ ] Chat / Broadcastが表示される
* [ ] 牢屋が生成される
* [ ] プレイヤーが牢屋内に収監される
* [ ] BossBarが表示される
* [ ] 刑期カウントが開始される

---

# 7. Arrested Player Protection

収監中のプレイヤーについて確認。

## Damage

* [ ] 他プレイヤーから攻撃されてもダメージを受けない
* [ ] モブから攻撃されてもダメージを受けない
* [ ] 落下ダメージを受けない
* [ ] 溺水ダメージを受けない
* [ ] 炎・溶岩でダメージを受けない

## Potion / Effects

* [ ] 耐性Vが付与される
* [ ] 水中呼吸が付与される
* [ ] 火炎耐性が付与される

## Survival Status

* [ ] 体力が減らない
* [ ] 満腹度が減らない
* [ ] 自然回復等による状態異常が問題を起こさない

## Crime Lock

* [ ] 逮捕中に草を壊しても再逮捕されない
* [ ] 逮捕中に花を踏んでも再逮捕されない
* [ ] 逮捕中にアイテムを捨てても再逮捕されない
* [ ] 逮捕中に30秒動かなくても再逮捕されない
* [ ] 逮捕処理が二重に発生しない

---

# 8. Jail

## Structure

* [ ] 5 × 5
* [ ] 高さ5
* [ ] 床が正しい
* [ ] 天井が正しい
* [ ] 鉄格子が正しい
* [ ] 四方向に保釈看板がある
* [ ] 看板の位置が正しい
* [ ] 看板の内容が正しい

## Jail Protection

収監中の牢屋について確認。

* [ ] 床を壊せない
* [ ] 天井を壊せない
* [ ] 鉄格子を壊せない
* [ ] 保釈看板を壊せない
* [ ] 牢屋のブロックを別のブロックへ置き換えられない
* [ ] 収監者自身が牢屋を壊せない
* [ ] 他プレイヤーも牢屋を壊せない

---

# 9. Bail

鉄インゴット5個による保釈。

## 正常

* [ ] 保釈看板をクリック
* [ ] 鉄インゴット5個を所持
* [ ] 保釈できる
* [ ] 鉄インゴット5個が消費される
* [ ] BossBarが消える
* [ ] 牢屋が撤去される
* [ ] プレイヤー保護が解除される
* [ ] プレイヤーが自由になる

## 鉄不足

* [ ] 鉄インゴット4個以下
* [ ] 保釈できない
* [ ] 鉄インゴットが消費されない
* [ ] BossBarが残る
* [ ] 牢屋が残る
* [ ] プレイヤー保護が継続する

## 収監者以外

* [ ] 他プレイヤーが保釈看板をクリック
* [ ] 収監者の刑期が変化しない
* [ ] 不正に保釈できない

---

# 10. Sentence

## 180秒

* [ ] 収監時に180秒から開始
* [ ] BossBarに残り時間が反映される
* [ ] 時間経過でカウントダウンする
* [ ] 0秒になる
* [ ] 自動的に解放される
* [ ] BossBarが消える
* [ ] 牢屋が撤去される
* [ ] プレイヤー保護が解除される

## Sentence中

* [ ] 刑期中に再逮捕されない
* [ ] 刑期中にBossBarが二重にならない
* [ ] 刑期が二重に進まない

---

# 11. Jail Collision

牢屋が既存の牢屋と重なる場合。

* [ ] 通常は現在地点に牢屋が生成される
* [ ] 既存の牢屋と重なる場合を確認
* [ ] 既存の牢屋を破壊しない
* [ ] 新しい牢屋が安全な位置へ移動する
* [ ] 収監者同士の牢屋が重ならない

---

# 12. Multiple Players

複数プレイヤーでの確認。

* [ ] Player Aを逮捕
* [ ] Player Bは通常プレイ可能
* [ ] AのBossBarがBに不要に表示されない
* [ ] Aの刑期がBに影響しない
* [ ] Aの保護がBに影響しない
* [ ] Aの牢屋をBが壊せない
* [ ] AとBを同時に逮捕できる
* [ ] それぞれ別々に刑期管理される
* [ ] Aを保釈してもBは収監されたまま

---

# 13. Restart

## Server Restart

* [ ] サーバー停止
* [ ] サーバー再起動
* [ ] Skript読み込み成功
* [ ] エラーがない
* [ ] 古いBossBarが残らない
* [ ] `/arrest status` が正常に動作する
* [ ] `/arrest on` で再稼働できる

## Restart後

* [ ] `/arrest on`
* [ ] 対象ワールドが再設定される
* [ ] 犯罪チェックが再開される
* [ ] Survivalで犯罪が検知される
* [ ] 対象ワールド以外では動作しない
