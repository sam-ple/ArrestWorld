# ARREST GAME - Test Guide

## 1. Startup

* [ ] Skriptの読み込み時にエラーがない

---

## 2. ON / OFF

### ON

```text
/arrest on
```

* [ ] ARREST GAMEがONになる
* [ ] 対象ワールドが設定される
* [ ] 犯罪チェックが動作する

### OFF

```text
/arrest off
```

* [ ] ARREST GAMEがOFFになる
* [ ] 犯罪チェックが停止する
* [ ] 犯罪を起こしても逮捕されない

### Status

```text
/arrest status
```

* [ ] ON / OFFと対象ワールドを確認できる

---

## 3. Common Conditions

共通の逮捕条件を確認。

* [ ] 対象ワールド + Survivalで犯罪を起こすと逮捕される
* [ ] 対象ワールド以外では逮捕されない
* [ ] Survival以外では逮捕されない
* [ ] 収監中は再逮捕されない

---

## 4. Arrest

犯罪発生から収監までの基本動作を確認。

* [ ] 罪状が表示される
* [ ] Title / Chat / Broadcastが表示される
* [ ] 牢屋が生成され、プレイヤーが収監される
* [ ] BossBarが表示され、刑期が開始する

---

## 5. Prisoner Protection

収監中のプレイヤーを確認。

* [ ] ダメージを受けない
* [ ] 体力・満腹度が減らない
* [ ] 耐性・水中呼吸・火炎耐性が機能する
* [ ] 収監中の犯罪処理が発生しない

---

## 6. Jail

* [ ] 5×5×5の牢屋が正常に生成される
* [ ] 保釈看板が正常に設置される
* [ ] 牢屋のブロック・看板をプレイヤーが壊せない
* [ ] 既存の牢屋と重なる場合、新しい牢屋が別の安全な位置に生成される

---

## 7. Bail

* [ ] 保釈看板をクリックすると、必要な保釈品があれば解放される
* [ ] 保釈品が正しく消費される
* [ ] 保釈品が不足している場合は解放されない
* [ ] 保釈時にBossBar・牢屋・保護が解除される

---

## 8. Sentence

* [ ] BossBarの残り時間がカウントダウンする
* [ ] 0秒になると自動的に解放される
* [ ] 解放時にBossBar・牢屋・保護が解除される
* [ ] 刑期が二重に進行しない

---

## 9. Multiple Players

* [ ] 複数プレイヤーを同時に収監できる
* [ ] プレイヤーごとに牢屋・BossBar・刑期・保護が独立している
* [ ] 一方を保釈しても、他のプレイヤーは収監されたまま

---

## 10. Restart

サーバー再起動後の復旧を確認。

* [ ] サーバー再起動時にエラーがない
* [ ] 古いBossBarが残らない
* [ ] `/arrest status` が正常に動作する
* [ ] `/arrest on` で再稼働できる
* [ ] 再稼働後、対象ワールド・共通条件が正常に機能する

---

## 11. Final Basic Test

最低限、以下の一連の流れが正常なら基本機能OK。

1. [ ] `/arrest on`
2. [ ] 対象ワールドのSurvivalで犯罪を起こす
3. [ ] 逮捕・罪状表示
4. [ ] 牢屋生成・収監
5. [ ] BossBar表示・刑期開始
6. [ ] 収監中にダメージを受けない
7. [ ] 牢屋を壊せない
8. [ ] 再逮捕されない
9. [ ] 保釈または刑期終了で解放
10. [ ] BossBar・牢屋・保護が解除される
11. [ ] `/arrest off`
12. [ ] 犯罪を起こしても逮捕されない
